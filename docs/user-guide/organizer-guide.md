## Getting Started

### Login

1. Navigate to the EventSphere login page
2. Enter your organizer email and password
3. Click "Login"

### Dashboard Overview

After logging in, you'll see your Organizer Dashboard with:
- List of all your expos
- Quick actions to create new expos
- Recent activity and notifications

## Creating an Expo

### Step 1: Basic Information

1. Click "Create New Expo" button
2. Fill in the required fields:
   - **Title**: Name of your expo (e.g., "Tech Innovation Expo 2024")
   - **Description**: Detailed description of the event
   - **Theme**: Category or theme (optional)
   - **Date Range**: Start and end dates
   - **Location**: Venue details including address, city, country

### Step 2: Save and Publish

1. Click "Save Draft" to save without publishing
2. Click "Publish" to make the expo visible to exhibitors and attendees
3. You can edit the expo later if needed

### Expo Status

- **Draft**: Not visible to exhibitors/attendees, still being set up
- **Upcoming**: Published and accepting registrations
- **Active**: Currently ongoing
- **Completed**: Event has ended
- **Cancelled**: Event cancelled

## Managing Floor Plans

### Creating a Floor Plan

1. Navigate to your expo → "Floor Plan" tab
2. Click "Create Floor Plan"
3. Set dimensions (width and height in meters)
4. Upload floor plan image (optional)
5. Click "Save"

### Adding Booth Spaces

1. Open the Interactive Floor Plan Editor
2. Click "Add Booth" button
3. Drag to position the booth on the floor plan
4. Configure booth details:
   - **Identifier**: Booth number/name (e.g., "A-101")
   - **Size**: Width and height
   - **Amenities**: Power outlets, internet, etc.
   - **Price Tier**: Standard, Premium, or Deluxe
5. Click "Save Booth"

### Assigning Booths to Exhibitors

1. Go to "Applications" tab
2. Click on an approved exhibitor application
3. Click "Assign Booth"
4. Select available booth from the floor plan
5. Confirm assignment

## Approving Exhibitors

### Reviewing Applications

1. Navigate to your expo → "Applications" tab
2. You'll see a list of pending exhibitor applications
3. Click on an application to review:
   - Company information
   - Category and products
   - Contact details
   - Registration details

### Approval Process

1. Review the exhibitor information
2. Click "Approve" or "Reject"
3. If approved, you can immediately assign a booth
4. The exhibitor will receive a notification

### Filtering Applications

Use filters to manage applications:
- **Status**: Pending, Approved, Rejected
- **Category**: Filter by exhibitor category
- **Date**: Sort by registration date

## Creating Schedules

### Adding Sessions

1. Navigate to your expo → "Schedule" tab
2. Click "Add Session"
3. Fill in session details:
   - **Title**: Session name
   - **Description**: Detailed description
   - **Category**: Keynote, Workshop, Panel, etc.
   - **Topic**: Main topic or theme
   - **Date & Time**: Start and end time
   - **Location**: Room name and capacity
   - **Speaker(s)**: Add speaker information
4. Click "Save Session"

### Managing Conflicts

The system automatically detects scheduling conflicts:
- Same speaker in overlapping sessions
- Room capacity exceeded
- Time overlaps

Resolve conflicts by adjusting session times or locations.

### Session Status

- **Scheduled**: Session is confirmed
- **Cancelled**: Session cancelled
- **Completed**: Session has ended

## Viewing Analytics

### Dashboard Analytics

1. Navigate to your expo → "Analytics" tab
2. View key metrics:
   - **Attendee Count**: Total registered attendees
   - **Session Popularity**: Most booked sessions
   - **Booth Traffic**: Booth reservation status
   - **Engagement Rate**: Overall engagement metrics

### Exporting Reports

1. Click "Export Report" button
2. Select report type:
   - Attendee list
   - Session attendance
   - Booth assignments
   - Analytics summary
3. Choose format: PDF, CSV, or Excel
4. Click "Generate Report" (may take a few moments)

## Managing Feedback

### Viewing Feedback Queue

1. Navigate to "Feedback" in the main menu
2. View all feedback submissions:
   - **Pending**: New feedback awaiting review
   - **Reviewed**: Feedback you've reviewed
   - **Resolved**: Issues that have been addressed
   - **Closed**: Completed feedback items

### Responding to Feedback

1. Click on a feedback item
2. Read the submission
3. Click "Respond" to add your response
4. Update status as you process the feedback
5. Assign to team members if needed

### Feedback Categories

- **Suggestion**: Feature requests and ideas
- **Bug Report**: Technical issues
- **Support Request**: General support needs

## Tips and Best Practices

1. **Plan Ahead**: Create your expo and floor plan well in advance
2. **Clear Communication**: Use detailed descriptions for sessions and expos
3. **Monitor Applications**: Regularly review and approve exhibitor applications
4. **Stay Organized**: Use categories and tags to organize sessions
5. **Engage with Feedback**: Respond to attendee and exhibitor feedback promptly

## Troubleshooting

### Can't create an expo?

- Ensure you're logged in as an organizer
- Check that all required fields are filled
- Verify your account has organizer permissions

### Exhibitor applications not showing?

- Check expo status (must be "upcoming" or "active")
- Verify you're viewing the correct expo
- Check application filters
